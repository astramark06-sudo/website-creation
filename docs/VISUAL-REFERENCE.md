# Screenshot-informed original design

Open Screenshot-informed design in Master Creator Studio. Select a PNG or JPEG you have permission to analyze, confirm permission, and request a draft. The browser decodes a bounded local image, samples a 96 by 96 grid, and classifies coarse aspect, palette family, edge variation and brightness. The server receives only four categorical observations plus the user's existing title and objective. Image bytes never leave the browser. Limits are 8 MiB, 16 megapixels and 8192 pixels on either axis. Unsupported formats, including SVG, are rejected.

The planner selects existing independently authored theme and layout presets. It does not recover exact colors, text, graphics, branding, source code or backend logic; edge variation is not semantic understanding of a page. Accepting the proposal replaces the current draft only after confirmation. The result is not a screenshot-to-code replica or proof of originality. Review the design and replace starter content before publication. No additional model, service or dependency is required.

Regression tests validate the category-only boundary. The browser test analyzes a synthetic PNG and verifies that only categorical observations are transmitted. The existing HTML reference analysis remains separate.

## Optional local model interpretation

The default category-only workflow is unchanged. To enable a separate semantic preset-selection workflow, start Studio with `python scripts/creator_studio.py --vision-model YOUR_INSTALLED_VISION_MODEL`. Use a compatible, locally installed Ollama vision model and verify the service is configured for local-only inference. No download, cloud API or new Python package is requested by Studio. Model support, memory needs, offline behavior and accuracy depend on your installation.

Choose an authorized screenshot without private information and separately consent to model analysis. The browser re-encodes a reduced JPEG, at most 768 pixels on either axis and 64 KiB, and sends it to Studio and the fixed loopback Ollama service. This mode sends image bytes; the default mode does not. The server bounds the encoding and frame dimensions and requires an installed non-remote model. Only enumerated design presets and one original page-structure selection are accepted. Model text, instructions, copied artwork, branding and code are not incorporated. The resulting project is unapproved and contains original starter placeholders. Real inference is not part of CI; the transport and browser request boundaries are tested with synthetic images and simulated responses.
